# Minutes — AI音声議事録 Webアプリ

ブラウザだけで動く音声議事録アプリ。リアルタイム文字起こし → AI議事録生成 → PDF/Word出力まで完結。

---

## ディレクトリ構成

```
VoiceMinutesWeb/
├── index.html              # メインエントリーポイント
├── README.md
│
├── css/
│   ├── base.css            # デザイントークン・リセット・タイポグラフィ
│   ├── layout.css          # アプリシェル・サイドバー・パネル構造
│   ├── components.css      # ボタン・フォーム・モーダル・トースト

│   └── modals.css          # 追加モーダルスタイル
│
├── js/
│   ├── nlp.js              # 日本語NLPエンジン（解析・抽出・ハイライト）
│   ├── speech.js           # Web Speech APIラッパー
│   ├── renderer.js         # DOMレンダリング（波形・文字起こし・議事録）
│   ├── exporter.js         # PDF / Word / Markdown / JSON / TXT 出力
│   └── app.js              # メインアプリケーションコントローラー
│
└── lib/                    # （将来のローカルライブラリ用）
    └── .gitkeep
```

## 使い方

1. `index.html` をブラウザで開く（Chrome / Edge 推奨）
2. **録音タブ**：「録音開始」ボタンを押してマイクを許可
3. 日本語で話す → リアルタイムで文字起こし
4. **議事録タブ**：「議事録を生成」または `Cmd+Enter` で生成
5. **出力タブ**：PDF・Word・Markdown などでダウンロード

## 機能一覧

### 録音・文字起こし
- Web Speech API による日本語リアルタイム認識（`ja-JP`）
- 連続認識（途切れても自動再起動）
- フィラー（えー、あのー等）の自動除去
- キーワードハイライト（決定事項：緑 / ToDo：茶 / 数字：赤）
- テキスト内インクリメンタル検索

### 議事録生成（完全オフライン）
| 機能 | 内容 |
|------|------|
| 議題抽出 | 「について」「に関する」等のパターンで自動抽出 |
| 決定事項 | 「決定」「合意」「こととした」等を認識 |
| ToDoテーブル | 担当者・期限を正規表現で自動抽出 |
| 主な議論 | キーワードスコアリングで重要文を抽出 |
| 次回予定 | 「次回」「また来週」等を認識 |
| モード | 詳細 / 簡潔 の2モード |

### 出力
| 形式 | 説明 |
|------|------|
| PDF | jsPDF。ヘッダー・フッター・表付き。付録（全文）オプション |
| Word | docx.js。スタイル・表・ページ番号付き |
| Markdown | Notion・GitHub等に貼り付け可能 |
| Plain TXT | メール・チャット向け |
| JSON | 構造化データ。他システム連携用 |
| 印刷 | ブラウザ印刷ダイアログ（A4最適化済み） |

## 技術仕様

| 項目 | 内容 |
|------|------|
| フロントエンド | Vanilla HTML / CSS / JavaScript（フレームワーク不使用）|
| 音声認識 | Web Speech API（Chrome / Edge対応）|
| PDF生成 | jsPDF 2.5.1（CDN）|
| Word生成 | docx.js 8.5.0（CDN）|
| フォント | Cormorant Garamond / DM Sans / DM Mono / Noto Serif JP（Google Fonts）|
| データ保存 | なし（すべてメモリ内処理）|
| 外部通信 | なし（完全オフライン NLP）|

## キーボードショートカット

| キー | 動作 |
|------|------|
| `Space` | 録音 開始 / 停止 |
| `⌘ + Enter` | 議事録を生成 |
| `⌘ + S` | PDFをダウンロード |
| `⌘ + P` | 印刷 |
